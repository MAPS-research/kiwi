Why mean() returns NA 7

In R, mean() returns NA as soon as one value in the vector is missing. This is deliberate: R will not guess what the missing value was, so it reports the result as unknown too.

To average only the values you have, pass na.rm = TRUE:

mean(survey$income, na.rm = TRUE)

Before you drop the missing values, check two things:

  • How many are missing: sum(is.na(survey$income)).
  • Whether they are missing at random. Compare respondents with and without an income value on age or region.
x̄ = (1/n) Σ xᵢ[display math · KaTeX]

If missingness depends on income itself, the mean of the observed values is biased. Lecture 3 covers this on pages 12–13.
