Notes

  1. 1
    Top bar. Unchanged: brand mark, class switcher, Switch to Student View, Logout (TopNav.tsx:210-242). The one addition is the Display-menu button in the same icon group (G4).
  2. 2
    Sidebar, 220 px (AdminLayout.tsx:119): ten system entries plus the admin app, and inside a class "Classes" expands into its nine class entries (ClassLayout.tsx:36-44). No entries are added or removed in Stage 1. Labels are as-is; "sidebar label = page title" is a Phase 5 rule.
  3. 3
    Page header and info alert (ClassEnroll.tsx:256-264). The page is the AdminPage container (900 px max), so at 1280 and at 1440 the content is the same 852 px wide; only viewports under ~1120 px (220 px sidebar + 900 px page) squeeze it.
  4. 4
    Enroll panel, compact. The label sits above the field, as on Edit Class (the tour's pattern to carry forward); today it sits on the outline. The helper repeats the label (tour), and "ENROLL USERS" is hard-coded in capitals (ClassEnroll.tsx:290); both go to Phase 5. This is the page's one filled primary.
  5. 5
    Toolbar, compact. Today "Email Selected" is a second filled primary (ClassEnroll.tsx:314-322); here it is secondary, and Remove is an outlined destructive action. Button labels never wrap (at ~960 px today they break onto two and three lines); when space runs out the search field moves to its own line instead.
  6. 6
    Roster table, compact rows (36 px). Role is a neutral outlined chip; status carries an icon and a label, and "Pending" (in progress) stays neutral (G1). Today both are saturated filled chips in every row (ClassEnroll.tsx:386-400). Long emails truncate in one line.
  7. 7
    Pagination, shown when there is more than one page (ClassEnroll.tsx:409-417).
  8. 8
    Floating chat launcher, as-is: 56 px, resting 24 px from the right and 96 px from the bottom (GlobalChatButton.tsx:34-40, :131-137). At 1280 and 1440 it clears the table; at the tour's ~960 px it covers the Status column. Its size, elevation and resting offset are Phase 3; the companion stamp inside it (dashed) is Phase 4; moving it is Stage 2.
