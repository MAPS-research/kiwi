# Small popups

> **Pattern, not component.** This section defines the shared behavior of small anchored overlays. It does not prescribe one reusable content component. Menus, searchable selectors, and compact pickers remain separate implementations that follow the same contract.

### Compact picker

The compact-picker pattern (a bounded local task with draft state and an explicit Apply) is implemented in product code by
`AnalyticsDateRangeControl`. Its current implementation is still MUI and is kept under
